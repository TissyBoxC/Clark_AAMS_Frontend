# 珂拉课程表 用户手册（网页版）

面向**普通用户**的网页端操作说明。App 端请见 [App 用户手册](../../Clark_AAMS/docs/user_manual.md)。

---

## 1. 登录

打开网页，用注册好的账号登录。支持三种方式：

- 用户名 + 密码
- 邮箱 + 密码
- 登录码（一次性）

登录后**按身份自动跳转**：普通用户进「今日概览」，管理员进管理台。
没有单独的管理员入口需要你自己找。

如果还没验证邮箱，登录后会看到一条提示，点「去验证邮箱」完成验证，
之后才能使用导入、识别和解析功能。

---

## 2. 工作台

登录后的第一页是「今日概览」，上面有四个常用入口：

| 入口 | 用来做什么 |
|---|---|
| 我的课表 | 看这一周有什么课 |
| 教务导入 | 从学校系统一次导入整学期 |
| 截图识别 | 拍下课表照片放进来 |
| 取件码回查 | 用 8 位码取回课表 |

左侧导航分三组：**总览**（今日概览、我的课表）、
**导入与识别**（教务导入、课表识别、取件码回查）、**帮助**。

账号信息在「今日概览」下方，可以复制登录码。
登录码相当于另一把钥匙，拿到它的人能登进你的账号——在公共电脑上用完请退出登录。

## 3. 课表

### 3.1 查看

进入「我的课表」即可看到周视图。

顶部可以翻周：上一周 / 第 N 周 / 下一周。不在本周时会多一个「回到本周」。
周信息里会显示这一周的起始日期。

### 3.2 编辑

支持手动增删改课程，**修改立即保存到服务器**，
换设备登录会自动同步。

课程字段：

| 字段 | 说明 |
|---|---|
| 课程名 | 必填 |
| 周次 | 哪几周上课，如 1-16 周 |
| 星期 | 周一到周日 |
| 节次 | 第几节课，如 1-2 节 |
| 地点 / 教师 | 选填 |

### 3.3 时间冲突

页面会列出时间冲突的课程。单双周交替的课不会被误判成冲突。

### 3.4 学期设置

可以设置学期开始日期、总周数、每节课时长。
设置好之后，翻周和「今天有什么课」才会算得准。

### 3.5 清空课表

在页面最下方。会删掉**全部**课程，账号和本机上的都清掉，之后无法找回。
如果只是某几门课不对，单独编辑那几门更稳妥。

## 4. 导入课表

### 4.1 教务导入

选你的学校，按提示操作。

导入页还提供一个「取回课表内容」的进阶方式：复制一段指令，
在学校的课表页面里运行它，再把结果粘回来。
这条路需要你会用浏览器的调试窗口，**没有把握就用截图识别**，更省事。

### 4.2 截图识别

上传课表截图，由 AI 识别成结构化课程。

**注意**：

- 识别结果是**草稿**，请逐条校对后再保存
- 会消耗每日次数（默认每天 20 次）
- 次数用完后等第二天，或联系管理员

### 4.3 取件码回查

如果课表已经在另一台设备上识别过，可以用 8 位取件码取回。

## 6. 常见问题

### Q：网页版改了课表，App 里没变？

**这是已知行为，不是 bug。**

网页版的课表存在服务器，App 的课表存在本机，两者目前**不同步**。
跨设备请用**取件码**搬移，或只在一个端上维护课表。

### Q：提示「今天的次数已用完」？

每个功能有独立的每日次数（识别 20 / 解析 50 / 取件码 20）。

次数每天恢复。**统计的是「尝试次数」**，识别失败的那次也算，
所以偶尔会遇到「没成功几次却没次数了」。

### Q：页面空白 / 样式错乱？

先强制刷新（Ctrl+F5）。如果还是这样，联系维护的同学。
