# Clark AAMS 用户手册（网页版）

面向**普通用户**的网页端操作说明。App 端请见 [App 用户手册](../../Clark_AAMS/docs/user_manual.md)。

---

## 1. 登录

打开网页，用注册好的账号登录。支持三种方式：

- 用户名 + 密码
- 邮箱 + 密码
- 登录码（一次性）

登录后**按身份自动跳转**：普通用户进工作台，管理员进管理后台。
没有单独的管理员入口需要你自己找。

---

## 2. 课表

### 2.1 查看

登录后进入工作台即可看到课表。

### 2.2 编辑

支持手动增删改课程，**修改立即保存到服务器**，
换设备登录会自动同步。

课程字段：

| 字段 | 说明 |
|---|---|
| 课程名 | 必填 |
| 周次 | 哪几周上课，如 1-16 周 |
| 星期 | 周一到周日 |
| 节次 | 第几节课，如 1-2 节 |
| 地点 / 教师 | 选填 |

## 5. 常见问题

### Q：网页版改了课表，App 里没变？

**这是已知行为，不是 bug。**

网页版的课表存在服务器，App 的课表存在本机，两者目前**不同步**。
跨设备请用**取件码**搬移，或只在一个端上维护课表。

### Q：提示「今日额度已用完」？

每个功能有独立的每日额度（识别 20 / 解析 50 / 取件码 20）。

额度每天重置。**统计的是「尝试次数」**，识别失败的那次也算，
所以偶尔会遇到「没成功几次却没额度了」。

### Q：页面空白 / 样式错乱？

先强制刷新（Ctrl+F5）。若是部署问题请联系管理员。
